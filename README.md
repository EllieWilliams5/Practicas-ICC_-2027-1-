# ICC 2027-1 · Soluciones de las prácticas de laboratorio

Soluciones de referencia del código de las prácticas del laboratorio de
**Introducción a Ciencias de la Computación**, semestre 2027-1,
Facultad de Ciencias, UNAM.

Cada solución usa solo los temas que se habían visto hasta esa práctica.
No incluye reportes, únicamente el código.

**Versión de Java:** JDK 21.

| Carpeta | Práctica | Contenido |
|---|---|---|
| `Practica01/` | Introducción a la terminal y JDK | Comandos de terminal e instalación del JDK |
| `Practica02/` | Primeros pasos en Java | Scripts de JShell, `Bienvenida.java` y `Errores.java` corregido |
| `Practica03/` | Introducción a Git y LaTeX | Documento de LaTeX, README de ejemplo y comandos de Git |
| `Practica04/` | Dándole memoria a un programa | Variables en JShell, comentarios, `printf` y el cotizador |

**Próximamente, la práctica 5...**

## Cómo ejecutar

- **Programas de Java**: dentro de la carpeta del programa,
  ```
  javac Archivo.java
  java Archivo
  ```
